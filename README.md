🌸 Age Calculator by Laura
A beautiful and responsive Age Calculator Web App built using HTML, CSS, JavaScript, Luxon, and Flatpickr.
This application allows users to select their date of birth and instantly calculate their exact age in years, months, and days.

✨ Features
🎀 Elegant pink glassmorphism UI design
📅 Date picker using Flatpickr
🕒 Accurate age calculation using Luxon
🌍 Timezone support (America/New_York)
⚠️ Error handling for:
-Empty input
-Invalid date
-Future date selection
📱 Fully responsive design

🛠 Technologies Used
1.HTML5
2.CSS3
3.JavaScript (Vanilla JS)
4.Luxon
 – Date & time handling
5.Flatpickr
 – Date picker

🌐 Deployment (GitHub Pages)
1.Go to Settings
2.Click Pages
3.Under Build and Deployment
-Source → Deploy from a branch
-Branch → main
-Folder → / (root)
4.Click Save
Your site will be live in a few seconds 🎉
